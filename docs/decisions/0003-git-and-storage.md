# Git 和存储

- 状态：`confirmed`
- 日期：2026-08-25

## 决策

- Android Git 引擎使用 JGit。
- 仓库默认放 App 私有目录。
- 表情修改触发同步；最近使用同步延迟可配置，默认 30 分钟，`0` 表示每次使用后立即同步，不设置人为最低间隔。
- 每次同步都检查远端，有更新时 rebase；不设计只拉取模式。
- 不提供 Wi-Fi-only。
- Git 作者名和邮箱由用户配置。
- 可自动判断的冲突自动处理，特殊情况才报告用户。
- 第一版只管理一个已有远端仓库，只支持 HTTPS Token。
- 后台远端轮询默认 30 分钟，可配置或关闭。

## 后果

QQ 进程需要 IPC 才能读取仓库。JGit 必须封装在实现层并做 Android 运行时测试。
