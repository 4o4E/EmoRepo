# App UI

- 状态：`confirmed`
- 更新：2026-08-26

## 技术

- 使用 Kotlin 和 Jetpack Compose Material 3。
- 第一版只适配 Android QQ 使用场景，不提供 TIM 入口。

## 页面

App 底部固定三个同级路由：

- `表情列表`：查看表情包并进入包内管理页。
- `添加表情`：选择目标表情包并从系统文件选择器批量导入图片。
- `软件设置`：显示仓库、同步和设备设置。

路由由 Navigation Compose 管理并保存各顶级页面状态。表情包管理页属于 `表情列表` 的子路由；顶部返回和系统返回都回到表情包列表，底部路由仍可直接切换。

- 顶级页面不显示全局 TopAppBar，页面身份由底部路由图标和文字表达。
- 底部路由选中时只改变图标和文字颜色，不显示额外的选中容器背景。
- 表情包管理子页面在内容区保留返回入口和当前表情包名称。

首次启动且尚未完成仓库配置时，不显示主导航，进入三步引导：

1. `仓库`：填写不含用户名、密码和查询参数的 HTTPS 远端；Token 对公开仓库可留空。
2. `身份和设备`：填写 Git 作者名、邮箱；设备 ID 使用自动生成值并允许修改。
3. `克隆`：汇总非敏感配置并开始克隆，显示进度和可读错误，不允许重复发起。

- 引导字段在开始克隆前全部校验；Token 不在汇总页回显。
- 克隆先写同级临时目录，成功后才切换为正式私有仓库；失败不得留下“已配置”状态。
- 克隆成功后进入主界面并立即加载表情包；后续启动直接进入主界面并请求同步。
- 已完成配置后，主界面显示表情包、最近同步状态、未推送状态、手动同步和设置入口。

仓库页进入表情管理页。设置页中的每一项必须接入实际行为，不保留仅保存但不生效的占位项：

- 仓库：显示脱敏 HTTPS 远端、同步状态、最近成功时间、最近错误和手动同步。
- Git 身份：编辑作者名和邮箱。
- 凭据：输入新 Token 后替换 Keystore 中的旧 Token并立即请求同步；页面不回显现有 Token。
- 同步：后台远端轮询间隔，`0` 表示关闭，其他值不得低于 15 分钟；使用记录同步延迟允许 `0`。
- 使用记录：设备 ID 和本设备最大记录数；修改设备 ID 按协议合并改名，修改数量后立即裁剪本设备记录。
- 提交：编辑非空提交信息，后续自动提交使用新值。

APK 签名证书摘要不属于当前 App 使用设置，不在首次引导或设置页展示。

## 表情包列表

- 支持列表和平铺两种布局，并保存用户的布局选择。
- 列表/平铺使用紧凑的 Material 3 单选分段按钮组，只显示列表和网格图标；图标必须提供可访问说明。
- 主页内容区第一行左侧显示 `共 n 个表情包，m 张表情`，右侧显示紧凑布局按钮组；`m` 是所有已加载表情包有效索引记录数之和。
- 主页不提供新建按钮；新建表情包入口位于 `添加表情` 页面。
- 平铺模式固定为一行四个表情包，不按屏幕宽度变成两列或三列。
- 两种布局都显示表情包封面、名称和表情数量。
- 表情包名称和数量位于同一行，数量在右侧对齐并使用小字号。
- 平铺卡片的封面减少外边距，图片下方使用深色信息条显示名称和数量，不再用大面积卡片边框包围内容。
- 显式 `icon` 记录是封面；没有显式封面时使用 `order` 最小的有效表情；空包显示占位图。
- 封面是 GIF 时自动循环播放，并按封面区域裁切填满。
- 在主页长按任意表情包卡片后进入显式排序模式并开始拖动；列表和平铺模式都允许跨可见项排序并在边缘自动滚动。
- 进入排序模式后，后续调整不再要求重复长按；按住卡片直接拖动即可。
- 排序模式在内容首行明确显示 `取消` 和 `完成`，并暂时隐藏布局切换；普通短按不再进入表情包。
- 拖动和松手只更新内存中的草稿顺序，不写仓库、不触发同步；可以连续调整多个表情包。
- 点击 `完成` 才调用仓库层一次性重写根目录 `index.jsonl` 并按表情修改同步策略提交任务。
- 点击 `取消` 或在排序模式按系统返回键会丢弃草稿并恢复进入排序前的顺序。
- 长按开始和拖动结束提供触觉反馈，拖动项使用浮起效果；普通状态短按仍进入表情包，不增加常驻拖动按钮。

## 表情包管理

- 表情网格固定为四列，不随屏幕宽度改成三列或五列。
- 普通模式下，表情项只显示图片预览，不显示常驻容器背景、内边距或 `png`、`jpg`、`gif` 等格式文本；点击图片打开大图预览。
- 多选状态使用选中边框和多选框表达，不恢复每项常驻容器底色。
- GIF 在表情卡片和大图预览中自动循环播放，其他图片继续使用带插值过滤的静态预览。
- 普通模式不显示多选框。点击顶部多选图标进入多选模式后，全部卡片显示多选框，点击卡片或多选框切换选择。
- 多选模式保留从多选框拖动连续选择；点击顶部关闭图标退出多选模式并清空选择。

## 导入确认

- `添加表情` 页面先选择目标表情包，并提供新建表情包入口。
- 目标表情包选择区复用主页的列表/四列平铺组件和同一组图标切换按钮；布局选择在两个页面间共享保存。
- 选择页保留封面、名称和数量，并使用选中颜色表达当前目标；选择页不启用拖动排序，避免选择目标时误改全局顺序。
- 系统文件选择器使用多选模式；页面不额外解释多选和二次确认等通用交互。
- 文件选择器返回后不立即写仓库，先显示目标表情包和选中数量；用户二次确认后才开始导入。
- 取消确认不导入任何图片，也不触发 Git 同步。
- 表情包管理页内的导入入口遵循相同的多选和二次确认规则。

## 全屏预览

- 从表情包内点击任意表情后进入全屏预览，并定位到被点击项。
- 预览按当前 `order` 顺序组成水平分页，未放大时左右滑动切换上一张或下一张。
- 当前页支持双指缩放、双击缩放、放大后单指拖动和惯性；缩放到边缘后允许继续切换相邻页。
- 切换页面后，每一页独立维护缩放状态；关闭预览后不保留该状态。
- GIF 在全屏预览中继续自动循环播放。
- 顶部显示关闭入口和 `当前页 / 总数`；系统返回键关闭预览。
- 长按当前预览打开操作菜单，提供 `导出` 和 `转发`。
- `导出` 使用系统文件保存位置选择器，以原始文件名和原始字节写出；取消位置选择不产生文件。
- `转发` 使用 Android 系统 Sharesheet 分享原文件，只对接收应用授予该文件的临时只读权限，不暴露仓库路径或其他文件。

## 首版边界

- 只管理一个仓库并跟踪远端默认分支。
- 不提供多仓库切换、SSH、公共目录直接管理或本地空仓库初始化。
- 第一阶段错误只在 App 内显示，不申请系统通知权限。
