# `index.jsonl`

- 状态：`confirmed`
- 更新：2026-08-30

本文只规定 `<pack-name>/index.jsonl` 的表情记录。仓库根目录同名文件按 [`root-index-jsonl.md`](root-index-jsonl.md) 保存表情包顺序。

## 编码

- UTF-8，无 BOM。
- 一行一个完整 JSON 对象，不允许跨行格式化。
- 空行忽略。
- 文件末尾保留一个换行。
- 字段按 `name, md5, ext, time, icon` 输出；可选字段缺失时不输出 `null`。

## 记录

```jsonl
{"name":"3e9e49d980b3afd24997ca6bb6af201b.png","md5":"3e9e49d980b3afd24997ca6bb6af201b","ext":"png","time":1773665447555,"icon":true}
{"name":"aa12.gif","md5":"aa120000000000000000000000000000","ext":"gif","time":1773665447000}
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---:|---|
| `name` | string | 是 | 表情包目录内文件名 |
| `md5` | string | 是 | 图片内容 MD5，也是合并主键 |
| `ext` | string | 是 | 根据文件内容识别的规范扩展名 |
| `time` | int64 | 是 | 当前协议中的稳定时间戳，毫秒 |
| `icon` | boolean | 否 | `true` 表示显式包封面 |

- `ext` 只允许 `png`、`jpg`、`jpeg`、`gif`、`webp`，并使用小写。
- `time` 是表情首次加入仓库的 Unix 毫秒时间；移动、排序和设置封面不修改它。

## 顺序

- JSONL 非空行的物理顺序是唯一最终显示顺序，第一条记录显示在最前。
- 读取器不得再按 `md5`、名称、时间或其他字段二次排序。
- 新导入表情插入第一条记录；已有记录的 JSON 内容和相对顺序保持不变。
- 拖动、名称、时间或使用频率排序只重排完整 JSONL 行，不修改记录字段。
- 删除只移除目标行；移动到目标包时把移动记录插入目标索引第一行。

## 封面

- 每个索引最多一个 `icon: true`。
- 没有显式封面时，选择文件中第一条有效表情作为运行时封面，但不自动补写 `icon`。
- 清空封面只移除 `icon` 字段。

## 读取和写入

- 已发布的旧记录若全部带 `order`，首次读取时先按 `order, md5` 恢复旧可见顺序，再原子移除所有 `order` 字段；新旧记录混合时拒绝迁移。
- 记录指向的图片不存在时跳过显示，不静默删除索引行。
- 非法 JSON 行使整个索引进入错误状态，不得部分写回覆盖原文件。
- 重复 `md5`、未知字段或字段类型错误使整个索引进入错误状态，不采用最后一行覆盖。
- 写入使用同目录临时文件、刷新并原子替换，避免进程被杀产生半个索引。
- 不读取或生成 `index.json`。

## 验收

- 新增只增加首行，删除只移除对应行；排序只改变行序。
- 相同数据重复序列化得到逐字节一致内容。
- 路径逃逸、重复 `md5`、多个显式封面和非法字段能被检测。
