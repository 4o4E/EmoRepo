# `index.jsonl`

- 状态：`confirmed`
- 更新：2026-08-25

## 编码

- UTF-8，无 BOM。
- 一行一个完整 JSON 对象，不允许跨行格式化。
- 空行忽略。
- 文件末尾保留一个换行。
- 字段按 `name, md5, ext, time, icon, order` 输出；可选字段缺失时不输出 `null`。

## 记录

```jsonl
{"name":"3e9e49d980b3afd24997ca6bb6af201b.png","md5":"3e9e49d980b3afd24997ca6bb6af201b","ext":"png","time":1773665447555,"icon":true,"order":1024}
{"name":"aa12.gif","md5":"aa120000000000000000000000000000","ext":"gif","time":1773665447000,"order":2048}
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---:|---|
| `name` | string | 是 | 表情包目录内文件名 |
| `md5` | string | 是 | 图片内容 MD5，也是合并主键 |
| `ext` | string | 是 | 根据文件内容识别的规范扩展名 |
| `time` | int64 | 是 | 当前协议中的稳定时间戳，毫秒 |
| `icon` | boolean | 否 | `true` 表示显式包封面 |
| `order` | int64 | 是 | 唯一最终显示顺序，值小的在前 |

- `ext` 只允许 `png`、`jpg`、`jpeg`、`gif`、`webp`，并使用小写。
- `time` 是表情首次加入仓库的 Unix 毫秒时间；移动、排序和设置封面不修改它。

## 顺序

- UI 最终只按 `order` 升序展示。
- 相同 `order` 用 `md5` 升序稳定排序。
- 名称、时间或使用频率排序最终都写回 `order`。
- 新索引建议用 `1024` 的间隔分配顺序；插入时优先使用间隙。
- 无可用间隙或存在重复时，按当前有效顺序重新写为 `1024, 2048, ...`。

## 封面

- 每个索引最多一个 `icon: true`。
- 没有显式封面时，选择 `order` 最小的有效表情作为运行时封面，但不自动补写 `icon`。
- 清空封面只移除 `icon` 字段。

## 读取和写入

- 记录指向的图片不存在时跳过显示，不静默删除索引行。
- 非法 JSON 行使整个索引进入错误状态，不得部分写回覆盖原文件。
- 重复 `md5`、未知字段或字段类型错误使整个索引进入错误状态，不采用最后一行覆盖。
- 写入使用同目录临时文件、刷新并原子替换，避免进程被杀产生半个索引。
- 不读取或生成 `index.json`。

## 验收

- 单条修改只改变对应行；整体排序除外。
- 相同数据重复序列化得到逐字节一致内容。
- 路径逃逸、重复 `md5`、多个显式封面和非法字段能被检测。
