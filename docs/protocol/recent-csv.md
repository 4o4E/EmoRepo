# 最近使用 CSV

- 状态：`confirmed`
- 更新：2026-08-25

## 结构

每台设备只写自己的文件：

```text
recent/<device-id>.csv
```

```csv
package,name,time
404,3e9e49d980b3afd24997ca6bb6af201b.png,1775200000000
reply,aa12.gif,1775190000000
```

| 字段 | 含义 |
|---|---|
| `package` | 表情包文件夹名 |
| `name` | 表情图片文件名 |
| `time` | 最近使用时间，Unix 毫秒 |

## 规则

- UTF-8，无 BOM，首行为固定表头 `package,name,time`。
- 字段包含逗号、双引号或换行时按 RFC 4180 方式加引号，双引号写成两个双引号。
- 同一设备文件以 `(package, name)` 去重，只保留最大 `time`。
- 汇总多设备文件时仍以 `(package, name)` 去重并取最大 `time`。
- 输出按 `time` 倒序，相同时间按 `package`、`name` 升序稳定排序。
- 表情暂时不存在时跳过显示，不从其他设备的 CSV 删除。
- 使用记录本地立即写入，同步延迟可配置，默认 30 分钟。
- 同步延迟为 `0` 时，每次使用都立即请求同步，不设置人为最低间隔。
- 正数延迟用于合并多次使用记录；具体窗口算法在 `git/sync.md` 确认。
- 首次设备 ID 为 `android-` 加 8 位随机小写十六进制，持久保存并允许用户修改。
- 设备 ID 只允许 ASCII 字母、数字、`-` 和 `_`，长度为 1 到 48。
- 改名时把旧文件和新文件按本文件规则合并，原子写入新文件后删除旧文件。
- 每台设备默认最多保留 30 条，可配置；配置为 `0` 时不记录使用历史，也不触发使用记录同步。

## Git 冲突

同一路径 CSV 发生冲突时，解析两边记录，按上述键取最大 `time` 并重新写入，不报告普通可解析冲突。
